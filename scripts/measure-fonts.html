Font metric capture

Everything the engine knows about text width comes from this page. Open it in Chrome, wait for Inter to load, then paste each block where it says to. The engine must never call measureText itself — that is the whole point of the tables.

1. Packed advance tables → packages/engine/src/measure/fontTables.ts

Advances of each character measured in isolation, as integers of 1/10000 em, positionally aligned to CHARSET. Isolated characters carry no kerning, so these are exact.

2. Reference widths → packages/engine/tests/fixtures/reference-widths.json

Whole-string measurements. These are what the ±3% margin is asserted against: the gap between them and the sum of the advances above is exactly the kerning and bold-model error that stringFitScale corrects.
